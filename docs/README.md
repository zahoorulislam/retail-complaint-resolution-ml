# Documentation Index

Project: **Using Machine Learning to Predict Complaint Resolution Outcomes in Retail Banking: Evidence from Open Consumer Financial Complaint Data**

This `docs/` folder explains the project workflow, data access, research questions, notebook sequence, model results, business findings, limitations, and governance controls. It is designed to support reproducibility and provide a clear guide for reviewers who want to understand the project without reading every notebook line by line.

## Documentation Files

| File | Purpose |
|---|---|
| `01_project_overview.md` | Summarises the business problem, project objective, stakeholders, scope, and expected business value. |
| `02_data_access_and_preparation.md` | Explains how to download the raw CFPB data, where to place it, and how Notebook 01 prepares the processed dataset. |
| `03_notebook_execution_guide.md` | Provides the recommended notebook run order, inputs, outputs, and execution notes. |
| `04_research_questions_and_hypotheses.md` | Lists the four research questions, hypotheses, and the analytical method used for each question. |
| `05_eda_and_hypothesis_testing_summary.md` | Summarises the exploratory analysis and hypothesis testing results from Notebooks 02 and 03. |
| `06_model_training_and_evaluation.md` | Documents model design, features, class imbalance treatment, evaluation metrics, and model performance. |
| `07_model_interpretation_and_business_findings.md` | Summarises feature importance, error analysis, subgroup performance, and business recommendations. |
| `08_governance_limitations_and_roadmap.md` | Captures limitations, responsible AI considerations, implementation roadmap, and monitoring controls. |

## Notebook Sequence

Run the notebooks in this order:

1. `01_data_extraction_colab_csv_v2.ipynb`
2. `02_exploratory_analysis_v2.ipynb`
3. `03_hypothesis_tests_v2.ipynb`
4. `04_model_training_v2.ipynb`
5. `05_model_interpretation_v2.ipynb`

## Main Output Folders

| Folder | Contents |
|---|---|
| `data/raw/` | Raw CFPB complaint CSV downloaded by the user. |
| `data/processed/` | Processed retail banking complaint dataset generated by Notebook 01. |
| `outputs/tables/` | CSV tables generated by EDA, hypothesis testing, model training, and interpretation. |
| `outputs/figures/` | Figures and charts generated by the notebooks. |
| `outputs/models/` | Saved trained models and preprocessing pipelines. |
| `reports/` | Interim or final capstone report files. |

## Important Use Note

The model is intended for **decision support and complaint-risk triage**, not automated complaint decisions. Results should be interpreted as predictive associations, not causal proof.
