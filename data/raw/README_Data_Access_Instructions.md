# Raw Data Access Instructions

The raw dataset used in this project is the public **Consumer Complaint Database** provided by the **Consumer Financial Protection Bureau (CFPB)**.

The raw data can be downloaded from the CFPB website:

https://www.consumerfinance.gov/data-research/consumer-complaints/#get-the-data

## Steps to Download the Raw Data

1. Open the CFPB Consumer Complaint Database page using the link above.
2. Scroll to the section titled **Get the data**.
3. Download the complaint database file in CSV format.
4. After downloading, rename the file as:

```text
complaints.csv
```

5. Place the downloaded file in the following project folder:

```text
retail-complaint-resolution-ml/
└── data/
    └── raw/
        └── complaints.csv
```

## Important Note About File Size

The raw CFPB complaint file is very large and is **not included directly in this GitHub repository**. To keep the repository lightweight and avoid upload limits, the raw data file should be downloaded separately by each user.

The repository contains the code, notebooks, processed outputs, and documentation needed to reproduce the analysis after the raw file is placed in the correct folder.

## Expected Raw Data Path

The notebooks expect the raw CSV file to be available at:

```python
data/raw/complaints.csv
```

For Google Colab execution, the project uses the following expected path:

```python
/content/drive/MyDrive/retail-complaint-resolution-ml/data/raw/complaints.csv
```

## Reproducing the Data Preparation

After placing the raw file in `data/raw/`, run the notebooks in this order:

```text
01_data_extraction_colab_csv_v2.ipynb
02_exploratory_analysis_v2.ipynb
03_hypothesis_tests_v2.ipynb
04_model_training_v2.ipynb
05_model_interpretation_v2.ipynb
```

The first notebook filters the CFPB dataset for relevant retail banking products and the 2017–2025 study period. It then creates the processed dataset used in the later exploratory analysis, hypothesis testing, model training, and model interpretation notebooks.

## Data Availability Statement

The raw data is publicly available from the CFPB Consumer Complaint Database. The processed dataset is generated by the project notebooks after applying the project-specific filters, cleaning rules, and feature-engineering steps.

Because of the size of the raw data file, users should download it directly from the CFPB website and place it in the required `data/raw/` folder before running the analysis.
